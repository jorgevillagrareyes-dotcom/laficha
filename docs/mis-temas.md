# Mis temas

Tus temas **guardados** y **estudiados**. Se guardan solo en este navegador y dispositivo; no se envían a ningún servidor. Márcalos con los botones que aparecen bajo el título de cada resumen.

## Usar sin conexión

Guarda el sitio completo en este dispositivo para estudiar sin internet (por ejemplo, en el turno). Después, cada vez que entres con conexión, las páginas se actualizan solas.
